DOPP RADAR

Política de Privacidad

Esta política explica cómo DOPP RADAR trata la información que recibe cuando una persona utiliza el canal de WhatsApp asociado al servicio.

Última actualización: 24 de septiembre de 2026Ámbito: DOPP RADAR / WhatsApp

1. Responsable del tratamiento

DOPP RADAR es un proyecto privado utilizado para recibir, organizar y analizar referencias, mensajes y archivos enviados voluntariamente a su canal de WhatsApp.

Para cuestiones de privacidad, utiliza el canal de contacto que se facilite junto al servicio.

2. Qué información puede recibirse

DOPP RADAR puede recibir, cuando el usuario decide enviarlos:

  • mensajes de texto;
  • enlaces y URLs;
  • imágenes y capturas de pantalla;
  • documentos;
  • audios o notas de voz;
  • vídeos;
  • metadatos técnicos necesarios para procesar el mensaje, como identificador del mensaje, fecha, tipo de contenido y remitente.

3. Finalidad del tratamiento

La información se utiliza para recibir, conservar, clasificar, deduplicar y preparar referencias para su análisis dentro de DOPP RADAR. El sistema puede identificar el tipo de contenido, detectar enlaces y almacenar temporalmente los archivos originales para su posterior revisión.

El contenido no se utiliza para publicidad comportamental ni se vende a terceros.

4. Base de uso

El tratamiento se produce porque el usuario envía voluntariamente el contenido al canal de DOPP RADAR con la finalidad de que sea recibido y procesado por el servicio.

5. Proveedores y comunicaciones

DOPP RADAR utiliza WhatsApp Business Platform, un servicio de Meta, para transportar los mensajes y eventos técnicos necesarios para que el contenido llegue al sistema.

También pueden intervenir proveedores técnicos de infraestructura estrictamente necesarios para alojar, transportar o almacenar la información. Estos proveedores no reciben autorización para utilizar los datos con fines propios ajenos a la prestación del servicio.

6. Conservación

Los mensajes y archivos se conservan durante el tiempo necesario para la finalidad para la que fueron enviados, para mantener la trazabilidad técnica y para evitar duplicados. Cuando dejan de ser necesarios, pueden eliminarse o archivarse de acuerdo con la operativa del proyecto.

7. Seguridad

Se aplican medidas técnicas para reducir accesos no autorizados, incluyendo validación de webhooks, control de secretos fuera del repositorio de código, deduplicación y almacenamiento separado de credenciales. Ningún sistema conectado a Internet puede garantizar seguridad absoluta.

8. Datos sensibles y contenido de terceros

No se debe enviar información sensible, confidencial o datos personales de terceros salvo que exista una base legítima para hacerlo. El usuario es responsable del contenido que decide remitir al canal.

9. Derechos y solicitudes

El usuario puede solicitar información sobre sus datos, su corrección o eliminación, cuando proceda, utilizando el canal de contacto facilitado por DOPP RADAR.

10. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de DOPP RADAR, los proveedores técnicos utilizados o los requisitos legales aplicables. La versión vigente se publicará en esta misma URL.
